Privacy Policy for SnapDownload HD

Effective Date: October 31, 2026 • Version: 1.0.0 • ✓ 100% Client-Side Private

Summary: What You Need to Know

  • 🛡️
    Zero Cloud Uploads: Images, URLs, and pages inspected by SnapDownload HD stay 100% in your local browser memory. Nothing is sent to our servers.
  • 💻
    Client-Side Conversion & ZIP: Format conversions (WebP/AVIF to PNG/JPG) and .ZIP file archiving run entirely on your CPU via HTML5 Canvas and Web Workers.
  • 🚫
    Zero Tracking or Telemetry: We do not track your browsing history, clicks, search queries, or IP addresses. We do not use Google Analytics or tracking cookies.
  • 🔑
    Gumroad License Verification: If you purchase a Pro license, your entered license key is verified directly with Gumroad's secure licensing API.

1. Single Purpose & Core Mission

SnapDownload HD is a browser extension engineered to help users discover, filter, preview, format-convert, and bulk-download images from active web pages. It was built with a strict "Local-First, Privacy-First" architecture.

2. Data Collection and Processing

We do not collect, transmit, distribute, or sell any of your personal data. Below is a detailed breakdown of how technical data is handled:

Data Category Collected? Storage Location Purpose
Web Page Images & URLs No Temporary Browser Memory (RAM) Displaying previews and executing downloads on user request. Discarded when popup closes.
Browsing History & PII No None SnapDownload HD never tracks or logs pages visited.
Filter Preferences Locally Only chrome.storage.local Remembers your minimum width, height, and preferred file format settings across sessions.
Pro License Key Locally & Sync chrome.storage.local / sync Stores your active Pro activation state so Pro features remain unlocked.

3. Permissions Justifications

SnapDownload HD requests minimal browser permissions strictly necessary for its advertised functionality:

  • activeTab: Used strictly when the user opens the extension to query images, CSS backgrounds, and canvas elements on the currently active tab.
  • scripting: Injects the isolated harvester script to resolve DOM image attributes, determine dimensions, and execute auto-scrolling when commanded by the user.
  • downloads: Triggers the browser's native file saving dialog for individual images and generated .ZIP archives.
  • storage: Retains user filter settings and local Pro activation credentials.

4. Third-Party Services & Gumroad Verification

SnapDownload HD does not integrate third-party ad networks, telemetry trackers, or crash-reporting SDKs.

The only external network request made by the extension occurs when a user explicitly submits a license key to unlock SnapDownload HD Pro. In this case, the extension sends a POST request directly to https://api.gumroad.com/v2/licenses/verify containing the product identifier and entered key. The verification response is stored locally in your browser storage.

5. Data Security

Because all image inspection, resizing, WebP/AVIF to PNG/JPG rasterization, and ZIP compilation happen locally in the browser runtime, your sensitive web graphics, design assets, and private dashboard images never traverse third-party servers.

6. Changes to this Privacy Policy

Any updates to this Privacy Policy will be reflected on this page with an updated "Effective Date". Continued use of the extension following any updates constitutes acceptance of the revised policy.
