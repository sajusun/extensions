Privacy Policy

Effective Date: October 2026 • Version: 1.0.0 • Target Browser: Microsoft Edge

🛡️ Executive Summary: 100% Client-Side Architecture

EdgePDF SmartTools was built from day one around a strict local-first privacy standard. When you open a PDF contract, tax document, bank statement, or research paper in Microsoft Edge, your documents NEVER leave your device.

We do not own remote document processing servers, we do not upload files, and we do not track or log what you read, copy, or export.

1. Information We Do NOT Collect

Because EdgePDF SmartTools runs 100% locally in your browser memory:

  • Zero Document Content: Text, tabular figures, scanned images, and metadata inside your PDFs are parsed directly on your CPU via client-side Web Workers.
  • Zero Browsing History: We do not track, log, or transmit the URLs or file paths of documents you open.
  • Zero Personal Identification: No names, email addresses, or IP addresses are collected during standard usage.
  • Zero Ad Tracking: No tracking cookies, third-party analytics pixels, or advertising SDKs are included.

2. Browser Permissions & Technical Justification

To operate seamlessly inside the Microsoft Edge built-in PDF viewer, the extension requests minimal permissions:

Permission Technical Purpose
activeTab Allows EdgePDF to run only when the user clicks the extension or uses a keyboard shortcut on the active PDF tab. It never inspects background tabs.
storage Used exclusively to persist your local user preferences (such as dark reader mode state and daily export quota counters) in chrome.storage.local.
scripting Used to inject the client-side area snip OCR crosshair canvas into the current tab when you press Alt + Shift + O.
contextMenus Adds convenient right-click options ("Extract Table to Excel", "Snip with OCR") directly to your Edge viewer context menu.

3. Pro License Verification (Gumroad)

If you purchase EdgePDF Pro, license verification is performed securely via the official Gumroad API (https://api.gumroad.com).

This request sends only the license key you manually entered to verify validity. No browsing history, document data, or computer identifiers are ever transmitted with this verification.

4. Optional AI Summarizer (BYOK)

EdgePDF provides basic local document summaries without any network connection. For users who choose to enable advanced AI summarization via OpenAI or Google Gemini:

  • This feature is strictly opt-in and requires you to provide your own API key (Bring-Your-Own-Key).
  • Requests are made directly from your browser to OpenAI or Google Gemini's official API endpoints.
  • Your API key is stored securely in your browser's local encrypted storage and is never transmitted to us or any intermediary server.

5. Compliance with Store Developer Policies

EdgePDF SmartTools complies fully with the Microsoft Edge Add-ons Developer Agreement and Manifest V3 security standards. We guarantee that user data is never sold, leased, or transferred to third-party data brokers or advertising networks.

6. Contact & Questions

If you have questions regarding this Privacy Policy or require enterprise audit verification, please reach out via the official developer support channel on our EdgePDF overview page.
